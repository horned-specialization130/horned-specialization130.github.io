## ❓ Frequently Asked Questions

### Why is the app showing red even though I haven't used Claude much?

The app checks for **all** usage patterns. If you're running batch processes or have multiple browser tabs open with Claude, that counts. You might also be part of a shared workspace where others' usage affects the limit.

### Do I need a Claude API key?

For **Claude Code** usage, yes, you'll need to set up your API key in the app's settings. The app will guide you through this the first time you open it. For **Claude.ai** (the website), no API key is needed—the app detects your logged-in browser session.

### Can I run this alongside other monitoring tools?

Yes, absolutely. The app uses minimal system resources and won't conflict with other software.

### How often does the app update the usage data?

It refreshes every 30 seconds by default. You can change this in settings to be as frequent as every 5 seconds or as slow as every 5 minutes.

### What happens when I reach the rate limit?

The app won't stop you from using Claude, but it will clearly warn you before you hit the limit. Once you're limited, the pet stays dark until your quota resets (usually within a few hours).

## 🛠️ Troubleshooting

### The app won't download

- Try right-clicking the download link and selecting **"Save link as..."**
- Check your internet connection
- Try a different browser (Chrome, Edge, or Firefox)

### The app won't install

- Make sure you closed all other programs before running the installer
- Temporarily disable your antivirus if it blocks the installation (then re-enable it)
- Run the installer as administrator: right-click the file and select **"Run as administrator"**

### The pet is not showing

- Check the **System Tray** (the arrow up icon at the bottom-right of your screen). The app might be hidden there.
- In the tray, right-click the paw icon and select **"Show Pet"**
- Check if your display scaling is set between 100%-150% in Windows Settings. Extreme scaling might push the pet off-screen.

### The usage numbers seem wrong

- Click the pet and select **"Refresh Now"** to manually update
- Make sure you're logged into the correct Claude account in your browser
- Restart the app by right-clicking the pet and selecting "Restart"
