部署指引（首次使用必看）
1) 打开 supabase.com 注册免费账号，New project（区域建议选 Singapore）。 2) 左侧 SQL Editor 执行建表语句（见随附《部署指引.md》）。 3) Project Settings → API，复制 Project URL 与 anon public key。 4) 回到本工作台「同步设置」填好三项并保存，会自动拉取 / 推送。 5) 把「团队空间 Key」发给同事，他们填相同 Key + 相同 URL/Key 即进同一空间。 注意：anon key 会暴露在前端，所以空间 Key 相当团队密码，勿外泄；不同团队请用不同 Key 隔离。
